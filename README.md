# 指尖花 · Fingertip Bloom

用摄像头识别手部骨骼，**握拳收成花苞、张开手掌让粒子花绽放**。
纯前端实现，不需要装任何插件，MediaPipe 的模型和运行时都在本仓库 `vendor/` 里，离线也能跑。

**线上地址：https://ts-jj.github.io/fingertip-bloom/**

---

## 怎么玩

打开页面后浏览器会询问摄像头权限，点「允许」。

| 动作 | 效果 |
|---|---|
| 张开手掌 | 花瓣完全绽放 |
| 握拳 / 收拢手指 | 收成花苞 |
| 手半开 | 花朵半开，跟随开合程度连续变化 |
| 手左右移动 | 花朵视差微移，有空间纵深感 |
| 手离开画面 | 缓慢回到花苞 |

按钮：

- **音乐**：背景音乐开关（默认播放）
- **换色**：点一下切下一个颜色；不点也会每 9.5 秒自动换
- **保存**：存成图片（不含界面元素）
  - 电脑上直接下载 PNG
  - 手机上弹出大图，**长按 → 保存到相册**
- **鼠标模式**：没有摄像头时，用鼠标上下移动控制花开
- **全屏**

## 手机上

- **手指上滑**绽放，**手指下滑**收成花苞
- 摄像头不可用时自动进入手指滑动模式，其余功能全部正常
- 保存按钮会弹出大图，长按存到相册（iPhone / 安卓 / 微信内都适用）

> 手机浏览器只在 HTTPS 或 localhost 下提供摄像头 API。
> 这个站点是 HTTPS 的，所以**手机上也能用摄像头手势识别**（用前置摄像头）。

## 技术要点

- **渲染**：原生 WebGL 点精灵 + 加法混合，约 11.6 万粒子，单次 draw call
- **花朵建模**：每片花瓣是一条 Catmull-Rom 曲线，横向宽度按纺锤形变化；
  三层花瓣（9 / 9 / 7 片）逐层抬高错开，形成真正的层叠
- **后处理**：亮部提取 → 两轮高斯模糊 → ACES 色调映射 + 镜头色差 + 暗角 + 胶片颗粒
- **音乐驱动**：`AnalyserNode` 读低频，用慢速基线提取鼓点，驱动花朵胀缩
- **手势**：MediaPipe HandLandmarker 取 21 个关键点，
  开合度 = 五指指尖到腕点距离均值 ÷ 掌长
- **自适应画质**：低帧率时先降渲染分辨率，再抽稀粒子；
  保存图片时会临时把画质拉满，存出来的始终是高清图

## 文件

```
index.html                    整个应用（单文件）
bloom.mp3                     背景音乐
vendor/                       MediaPipe 运行时（已本地化）
├── vision_bundle.mjs
├── hand_landmarker.task      手部关键点模型
└── wasm/                     WebAssembly 推理后端
```

## 本地运行

```bash
python serve.py      # 或任意静态服务器
```

不要直接双击 `index.html` —— 浏览器硬性禁止 `file://` 页面调用摄像头。
